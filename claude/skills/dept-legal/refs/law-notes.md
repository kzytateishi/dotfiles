## 1. 民法(明治 29 年法律第 89 号)

一次情報: https://laws.e-gov.go.jp/law/129AC0000000089

### 契約類型

| 条 | 見出し | 要点 |
|---|---|---|
| **632 条** | 請負 | 当事者の一方が**仕事を完成すること**を約し、相手方がその**仕事の結果**に対して報酬を支払うことを約する契約 |
| **633 条** | 報酬の支払時期 | 報酬は**仕事の目的物の引渡しと同時に**支払う。引渡しを要しないときは 624 条 1 項(後払い)を準用 |
| **643 条** | 委任 | **法律行為をすること**を委託し、相手方が承諾することで効力を生ずる |
| **644 条** | 受任者の注意義務 | 委任の本旨に従い、**善良な管理者の注意**をもって事務を処理する義務 |
| **656 条** | 準委任 | 委任の規定は、**法律行為でない事務の委託**について準用する |

> **エンジニアの業務委託は、法律行為ではないので「準委任」(656 条経由で委任の規定が適用される)。** 契約書に「準委任」と書いてあるのはこれ。

### 報酬・中途終了

| 条 | 見出し | 要点 |
|---|---|---|
| **634 条** | 注文者が受ける利益の割合に応じた報酬 | 請負で、①注文者の責めに帰することができない事由で完成不能、②完成前に解除、のとき、**可分な部分の給付で注文者が利益を受けるなら、その割合に応じて報酬請求可** |
| **641 条** | 注文者による契約の解除 | **請負人が仕事を完成しない間は、注文者はいつでも損害を賠償して解除できる** |
| **648 条** | 受任者の報酬 | 特約がなければ無償が原則(1 項)。履行後の後払い(2 項)。**履行不能・中途終了の場合は既にした履行の割合に応じて報酬請求可(3 項)** |
| **648 条の 2** | 成果等に対する報酬 | 成果に報酬を紐付ける委任(成果完成型)。成果の引渡しと同時に支払(1 項)。**634 条を準用(2 項)** |
| **651 条** | 委任の解除 | **各当事者がいつでも解除できる(1 項)。** 相手方に不利な時期の解除等では損害賠償義務が生じ得る。ただしやむを得ない事由があるときは不要(2 項) |

### 契約不適合責任

| 条 | 見出し | 要点 |
|---|---|---|
| **559 条** | 有償契約への準用 | 売買の規定は、売買以外の**有償契約に準用**(性質が許さないときを除く) |
| **562 条** | 買主の追完請求権 | 種類・品質・数量が契約内容に適合しないとき、**修補・代替物の引渡し・不足分の引渡し**を請求できる |
| **563 条** | 買主の代金減額請求権 | 催告して追完がないとき、**不適合の程度に応じて**減額請求可。追完不能等は無催告で可 |
| **564 条** | 買主の損害賠償請求及び解除権の行使 | 562・563 条は、415 条の損害賠償、541・542 条の解除を妨げない |
| **566 条** | 目的物の種類又は品質に関する担保責任の期間の制限(売買) | **不適合を知った時から 1 年以内に通知**しないと権利行使できない。売主が引渡し時に悪意・重過失なら適用なし |
| **572 条** | 担保責任を負わない旨の特約 | 免責特約をしても、**知りながら告げなかった事実**については責任を免れない |
| **636 条** | 請負人の担保責任の制限 | **注文者の供した材料・与えた指図**による不適合は、請負人は責任を負わない。ただし請負人が不適当を知りながら告げなかったときは負う |
| **637 条** | 目的物の種類又は品質に関する担保責任の期間の制限(請負) | **注文者が不適合を知った時から 1 年以内に通知**しないと、追完請求・報酬減額請求・損害賠償・解除ができない(1 項)。請負人が悪意・重過失なら適用なし(2 項) |

> **566 条・637 条は「1 年以内に通知」であって「1 年以内に権利行使」ではない。** 通知さえすれば、権利行使自体は 166 条の消滅時効(5 年 / 10 年)に服する。旧法の瑕疵担保(除斥期間 1 年)とは構造が違うので、**混同しやすい。**
>
> **これらは任意規定なので、契約で伸ばすことも縮めることもできる。** だから契約書側で「無期限」にされる(→ [clauses.md #2](clauses.md#2-契約不適合責任の期間が長すぎる--無期限))。

### 損害賠償・遅延

| 条 | 見出し | 要点 |
|---|---|---|
| **415 条** | 債務不履行による損害賠償 | 債務の本旨に従った履行をしないとき等に賠償請求可。**帰責事由がないときは不可**(1 項ただし書) |
| **416 条** | 損害賠償の範囲 | **通常生ずべき損害**(1 項)。特別の事情による損害は、**当事者がその事情を予見すべきであったとき**に限る(2 項) |
| **419 条** | 金銭債務の特則 | 金銭債務の遅延損害金は、**遅滞の責任を負った最初の時点の法定利率**による。約定利率が高ければ約定利率(1 項)。損害の証明不要(2 項)。不可抗力を抗弁にできない(3 項) |
| **404 条** | 法定利率 | **年 3%**(2 項)。3 年を一期とする**変動制**(3 項) |

> **法定利率は現在 年 3%。** 2020 年 4 月の施行以来変動しておらず、**令和 11 年(2029 年)3 月 31 日まで年 3% で据置きが確定**している(法務省告示による第 3 期の判定)。出典: https://www.moj.go.jp/MINJI/minji07_00366.html
>
> **契約で 14.6% と定めるのは、法定利率より高い約定利率。** 419 条 1 項ただし書により有効に機能する。取適法の遅延利息率(年 14.6%)に揃えた数字として説明できる。

### 時効・その他

| 条 | 見出し | 要点 |
|---|---|---|
| **166 条** | 債権等の消滅時効 | **権利行使できると知った時から 5 年**、または**行使できる時から 10 年**(いずれか早い方) |
| **90 条** | 公序良俗 | 公の秩序又は善良の風俗に反する法律行為は無効 |
| **724 条** | 不法行為による損害賠償請求権の消滅時効 | 損害及び加害者を知った時から 3 年 / 不法行為の時から 20 年 |

> **90 条は、過度な競業避止・違約金条項の効力を争う根拠として持ち出されることがある。** ただし**「無効」と断定できるのは裁判所だけ**。レビューでは「範囲・期間・対価に照らして過度であり、効力が争われる可能性があるため弁護士に確認」と書く。

## 2. 著作権法(昭和 45 年法律第 48 号)

一次情報: https://laws.e-gov.go.jp/law/345AC0000000048

| 条 | 見出し | 要点 |
|---|---|---|
| **10 条 1 項 9 号** | 著作物の例示 | **プログラムの著作物** |
| **10 条 3 項** | — | プログラムの保護は、**プログラム言語・規約・解法には及ばない**。「解法」= アルゴリズム |
| **15 条 1 項** | 職務上作成する著作物の著作者 | 法人等の発意 + 業務従事者 + 職務上作成 + **法人等の名義で公表** + 別段の定めなし → 法人が著作者 |
| **15 条 2 項** | 同(プログラムの特則) | プログラムは、**「法人等の名義で公表」の要件が不要**。発意 + 業務従事 + 職務上作成 + 別段の定めなし → 法人が著作者 |
| **17 条** | 著作者の権利 | 著作者人格権(18〜20 条)と著作権(21〜28 条)を享有。**無方式主義**(2 項) |
| **18 条** | 公表権 | 未公表の著作物を公衆に提供・提示する権利 |
| **19 条** | 氏名表示権 | 著作者名を表示し、又は表示しないこととする権利。**3 項: 利益を害するおそれがなく公正な慣行に反しない限り省略可** |
| **20 条** | 同一性保持権 | 意に反する変更・切除・改変を受けない権利。**2 項 3 号: 特定の環境で実行可能にするため / より効果的に実行させるために必要な改変は除外。2 項 4 号: 性質・目的・態様に照らしやむを得ない改変は除外** |
| **27 条** | 翻訳権、翻案権等 | 翻訳・編曲・変形・脚色・映画化その他**翻案する権利** |
| **28 条** | 二次的著作物の利用に関する原著作者の権利 | 二次的著作物の利用について、原著作者が同種の権利を専有 |
| **59 条** | 著作者人格権の一身専属性 | **著作者人格権は、著作者の一身に専属し、譲渡することができない** |
| **61 条 1 項** | 著作権の譲渡 | 著作権は全部又は一部を譲渡できる |
| **61 条 2 項** | 同 | 譲渡契約で **27 条・28 条の権利が譲渡の目的として特掲されていないとき**は、**譲渡した者に留保されたものと推定する** |
| **113 条 11 項** | 侵害とみなす行為 | 著作者の**名誉又は声望を害する方法**による利用は、著作者人格権侵害とみなす |

**実務上の含意:**

- **「著作者人格権を譲渡する」と書いてある契約書は、59 条を確認していない。** だから実務は「不行使特約」を使う。**この誤りを見つけたら、契約書全体の作り込みを疑う根拠になる**
- **61 条 2 項の特掲は、甲側が入れてくるのが正当。** 削除交渉は筋が悪い(削っても甲が改修できず、双方が困る)
- **15 条 2 項により、乙の従業員が書いたコードの著作者は原則として乙(法人)。** 個人事業主が外注を使う場合は職務著作にならないので、**外注先との間で権利処理が必要**(これを飛ばして甲に譲渡すると履行不能になる)
- **10 条 3 項により、アルゴリズム自体は著作権で保護されない。** 「設計手法・ノウハウは留保する」という交渉の裏付けになる
- **20 条 2 項 3 号・4 号があるので、実務上必要な改変は同一性保持権の問題になりにくい。** ただし不行使特約は入れておくのが通例

## 3. 中小受託取引適正化法(取適法) — 旧・下請法

正式名称: 製造委託等に係る中小受託事業者に対する代金の支払の遅延等の防止に関する法律(昭和 31 年法律第 120 号)
**2026 年 1 月 1 日施行の改正後**。冒頭の ⚠️ を必ず参照。

一次情報: [e-Gov](https://laws.e-gov.go.jp/law/331AC0000000120) / [公取委・取適法](https://www.jftc.go.jp/partnership_package/toritekihou.html) / [運用基準(令和 7 年 10 月 1 日)](https://www.jftc.go.jp/houdou/pressrelease/2025/oct/251001_toriteki1-4.pdf)

### 適用対象(2 条 8 項・9 項)

**資本金基準に加えて、改正で従業員数基準が新設された**(資本金基準が適用されない場合に適用)。

**グループ A(3 億円 / 1000 万円 / 300 人)** — 製造委託、修理委託、特定運送委託、**プログラム作成委託**、運送・倉庫保管・情報処理の役務提供委託

| 委託事業者 | 中小受託事業者 |
|---|---|
| 資本金 3 億円超 | 3 億円以下(個人を含む) |
| 資本金 1000 万円超 3 億円以下 | 1000 万円以下 |
| **従業員 300 人超** | **300 人以下** |

**グループ B(5000 万円 / 1000 万円 / 100 人)** — プログラム**以外**の情報成果物作成委託(デザイン、映像・音声、文字・図形)、上記以外の役務提供委託

| 委託事業者 | 中小受託事業者 |
|---|---|
| 資本金 5000 万円超 | 5000 万円以下(個人を含む) |
| 資本金 1000 万円超 5000 万円以下 | 1000 万円以下 |
| **従業員 100 人超** | **100 人以下** |

> **⚠️ ソフトウェア(プログラム)開発の委託は 3 億円区分。5000 万円区分ではない。** 2 条 8 項 1 号が「情報成果物作成委託…にあつては、**政令で定める情報成果物に係るものに限る**」としてプログラムをグループ A に取り込み、3 号が「第一号の政令で定める情報成果物…を**除く**」としてグループ B から外す構造(政令 = 平成 13 年政令第 5 号。指定は**プログラム**、および役務では**運送・倉庫保管・情報処理**)。**間違えやすい最頻出ポイント。**

> **⚠️⚠️ ただし上記は「プログラムという成果物を納める」請負型(情報成果物作成委託)の話。準委任・稼働ベースの開発支援に当てはめてはいけない。** 稼働ベースの支援は**役務提供委託**で、二重に扱いが違う:
>
> 1. 役務提供委託でグループ A に入るのは政令指定の**運送・倉庫保管・情報処理**だけ。**開発支援はグループ B(5000 万円 / 100 人)**
> 2. さらに **取適法の役務提供委託は「業として行う提供の目的たる役務」の委託、つまり他者に提供する役務の再委託に限られる**(2 条 4 項)。**甲が自社で使うための開発支援は、そもそも取適法の適用自体がない**(→ [4. フリーランス法](#4-フリーランス法)の「取適法にない射程」)
>
> **契約類型(請負か準委任か)を確定する前に「ソフト開発だから 3 億円区分、適用あり」と判断しない。** 適用がないのに交渉で「取適法に触れます」と言うと、**間違っているうえに関係も壊れる**。法令名も条番号も正しいまま結論だけ誤るため、検算しても気づけない。

### 主な規定

| 条 | 内容 |
|---|---|
| **3 条 1 項** | **支払期日は、給付を受領した日から 60 日以内**でできる限り短い期間内。条文上「**検査をするかどうかを問わず**」と明記 |
| **4 条** | 取引条件の明示(旧・3 条書面) |
| **5 条 1 項** | 禁止行為 7 号: ①受領拒否 ②**支払遅延**(手形交付、及び支払期日までに満額の金銭と引き換えることが困難な支払手段の使用を含む) ③減額 ④返品 ⑤買いたたき ⑥購入・利用強制 ⑦報復措置 |
| **5 条 2 項** | 禁止行為 4 号: ①有償支給原材料等の対価の早期決済 ②不当な経済上の利益の提供要請 ③**不当な給付内容の変更・やり直し** ④**協議に応じない一方的な代金決定**(改正で新設) |
| **6 条** | **遅延利息 年 14.6%**(公正取引委員会規則で定める率)。改正で**減額の場合も対象**に(2 項新設) |
| **7 条** | 書類等の作成・保存 |
| **10 条** | 勧告 |

> **⚠️ 役務提供委託・特定運送委託では 5 条の一部が適用除外。** 5 条 1 項柱書は「次に掲げる行為(**役務提供委託又は特定運送委託をした場合にあつては、第一号及び第四号に掲げる行為を除く**。)」、5 条 2 項柱書は「(同じく**第一号に掲げる行為を除く**。)」と定める。つまり役務提供委託では **①受領拒否 ・ ④返品 ・ (2 項)①有償支給原材料等の早期決済は適用外**。
> 準委任・稼働ベースの案件でこれらを持ち出さない。**適用外の条項を根拠にすると、指摘そのものが崩れる。**

**改正のポイント:**

- **手形払いが原則禁止に。** 旧法 4 条 2 項 2 号の「割引困難と認められる手形の交付」は削除され、5 条 1 項 2 号(支払遅延)に統合。**電子記録債権・ファクタリングも「満額を支払期日までに得ることが困難なもの」は不可**
- **「協議に応じない一方的な代金決定」が新設**(5 条 2 項 4 号)。買いたたきと違い「市価」の認定が不要で、**交渉プロセスそのものに着目**する

### 検収遅延の扱い(運用基準)

- 受領日 = **検査の有無を問わず、受け取って自己の占有下に置いた日**
- 受領拒否が認められる「中小受託事業者の責めに帰すべき理由」は **2 つに限定**(給付内容が委託内容と異なる / 明示された納期に給付されない)。**委託側の検査都合は含まれない**
- **検査基準が不明確な場合・検査基準を恣意的に厳しくした場合は、受領拒否が認められない**と明記
- **検収締切制度(例: 月末検収締切・翌月末支払)で受領日から 60 日を超えると支払遅延**になる
- 情報成果物の特則: 合意があれば支配下に置いた日を起算日としない扱いも可能だが、**明示された納期日に委託事業者の支配下にあれば、内容確認の完了を問わず受領したものとして起算**

> **これが [clauses.md #3](clauses.md#3-みなし検収がない)・[#13](clauses.md#13-支払サイトが長すぎる--検収後起算で無限に伸びる) の裏付け。** 適用がある取引なら、「検収が終わらないから払わない」は法令上通らない。

## 4. フリーランス法

正式名称: **特定受託事業者に係る取引の適正化等に関する法律**(令和 5 年法律第 25 号)
**施行日: 令和 6 年(2024 年)11 月 1 日**

一次情報: [e-Gov](https://laws.e-gov.go.jp/law/505AC0000000025) / [公取委パンフレット(条文全文収録)](https://www.jftc.go.jp/file/flpamph.pdf)

### 誰に適用されるか(2 条) — **資本金要件なし**

| 用語 | 定義 |
|---|---|
| **特定受託事業者**(= フリーランス) | ①**従業員を使用しない個人**、②**代表者以外に他の役員がなく、かつ従業員を使用しない法人** |
| **業務委託事業者** | 特定受託事業者に業務委託をする事業者(**フリーランスも含む**) |
| **特定業務委託事業者** | ①従業員を使用する個人、②**二以上の役員がある、又は従業員を使用する法人** |

「従業員を使用」= **週所定労働時間 20 時間以上かつ 31 日以上の雇用見込み**。同居親族のみは該当しない。

> **相手がフリーランスなら、こちらの資本金がいくらでも適用される。** 取適法と違って規模要件が無いのがこの法律の要点。**一人法人同士の取引でも、発注側に 3 条の明示義務がかかる。**

### 義務の適用マトリクス(これが実務上いちばん効く)

| 対象 | 適用される義務 |
|---|---|
| 業務委託事業者(**すべて**) | **3 条 取引条件の明示** |
| 特定業務委託事業者(期間問わず) | 3 条明示 / **4 条 支払期日** / 12 条 募集情報の的確表示 / 14 条 ハラスメント体制整備 |
| **1 か月以上**の業務委託(施行令 1 条) | **5 条 7 つの禁止行為** |
| **6 か月以上**の業務委託(施行令 3 条) | 13 条 育児介護配慮 / **16 条 中途解除の 30 日前予告・理由開示** |

期間の判定は更新による継続を含む。更新と認められるのは、当事者同一 + 給付内容が一定程度同一 + **空白期間が 1 か月未満**。

### 主な規定

| 条 | 内容 |
|---|---|
| **3 条** | 取引条件の明示(給付の内容、報酬額、支払期日等)。**期間を問わず、すべての業務委託事業者に適用** |
| **4 条** | **支払期日は、給付を受領した日から 60 日以内**でできる限り短い期間内。「**検査をするかどうかを問わず**」。定めなかった / 60 日超で定めたときは、法律上みなしが働く |
| 4 条(再委託の例外) | **再委託である旨・元委託者の名称・元委託業務の対価の支払期日**の 3 つを追加明示した場合に限り、**元委託の支払期日から 30 日以内**で設定可。起算は実際の入金日ではなく**約定の元委託支払期日** |
| **5 条 1 項** | 禁止行為 5 号: 受領拒否 / 報酬の減額 / 返品 / 買いたたき / 購入・利用強制 |
| **5 条 2 項** | 禁止行為 2 号: 不当な経済上の利益の提供要請 / **不当な給付内容の変更・やり直し** |
| **16 条** | **6 か月以上**の業務委託で、解除**又は不更新**をしようとするときは **30 日前までに予告**。予告後、契約満了日までに請求されたら理由を開示 |

**注意点:**

- **5 条 2 項も「1 か月以上」が要件。** 1 項柱書の「以下この条において同じ」により 2 項にも及ぶ。**「2 項は期間要件なし」とする解説がネット上にあるが誤り**
- **遅延利息の規定は無い**(取適法との大きな違い)
- 役務提供委託の場合、5 条 1 項の 1 号(受領拒否)・3 号(返品)は適用外
- **取適法にない射程**: ①建設工事も対象(取適法は建設業法の建設工事が対象外) ②**自ら用いる役務の委託も対象**(取適法の役務提供委託は「他者に提供する役務」に限る)

### 取適法・独禁法との関係

出典: [特定受託事業者に係る取引の適正化等に関する法律と独占禁止法及び取適法との適用関係等の考え方](https://www.jftc.go.jp/file/fl_jftcguidelines.pdf)(令和 6 年 5 月 31 日公取委、令和 8 年 1 月 1 日改正)

- いずれにも違反する行為は、**原則としてフリーランス法を優先適用**
- ただし**義務が消えるわけではない**。優先関係は執行段階の調整。**相手がフリーランスで、かつ委託側が取適法の規模基準を満たせば、両法が重畳的にかかる**

## 5. 独占禁止法・公取委ガイドライン

### 優越的地位の濫用

- **独占禁止法 2 条 9 項 5 号**が行為類型を定義し、**19 条**が不公正な取引方法として禁止する、という構造
  - **イ**: 継続取引の相手方に、当該取引に係る商品・役務以外を購入させること
  - **ロ**: 継続取引の相手方に、自己のために金銭・役務その他の**経済上の利益を提供させる**こと
  - **ハ**: 受領拒否、引取り、**対価の支払遅延・減額**、その他**相手方に不利益となるように取引条件を設定・変更し、又は取引を実施する**こと
- **「優越した地位」は絶対的な市場支配力を要しない。** 取引の相手方との関係で**相対的に優越していれば足りる**。判断要素は ①取引依存度 ②市場における地位 ③取引先変更の可能性 ④その他取引の必要性。**大企業対中小企業に限らず、中小企業同士でも成立し得る**

一次情報: [優越的地位の濫用に関する独占禁止法上の考え方](https://www.jftc.go.jp/dk/guideline/unyoukijun/yuetsutekichii.html)(平成 22 年 11 月 30 日策定、改正 平成 29 年 6 月 16 日、**改正 令和 8 年 1 月 1 日**)

> **⚠️ `jftc.go.jp/hourei_files/yuuetsutekichii.pdf` の PDF 版は平成 29 年で更新が止まっており現行版ではない。** 引用するときは上記 HTML 版から。

### フリーランスガイドライン(競業避止・秘密保持・知財)

正式名称: **フリーランスとして安心して働ける環境を整備するためのガイドライン**(令和 3 年 3 月 26 日策定、令和 6 年 10 月 18 日改定。内閣官房・公正取引委員会・中小企業庁・厚生労働省)
本体 PDF: https://www.jftc.go.jp/houdou/pressrelease/2024/oct/241018_freelancegl2.pdf

**秘密保持義務・競業避止義務・専属義務**(第 4-3(11)):

> 合理的に必要な範囲でこれらの義務を設定することは、直ちに独占禁止法上問題となるものではない。**しかし**…一方的に**合理的に必要な範囲を超えて**秘密保持義務、競業避止義務又は専属義務を課す場合であって、当該フリーランスが今後の取引に与える影響等を懸念してそれを受け入れざるを得ない場合には、**優越的地位の濫用として問題となる(独占禁止法 2 条 9 項 5 号ハ)**

想定例として挙げられているもの:
- **実績の公表を制限する秘密保持義務**(役務提供の事実が新たな発注事業者獲得上重要であるにもかかわらず、合理的に必要な範囲を超えて公表を制限すること)
- 既に育成費用を回収し終わったにもかかわらず、費用回収を理由に一方的に競業避止義務・専属義務を設定すること

判断要素: 義務の内容・期間が目的に照らして過大か、不利益の内容、**補償金等の有無・水準**、差別的か、通常の内容との乖離。

**役務の成果物に係る権利の一方的な取扱い**(第 4-3(6)):

> 取引上の地位がフリーランスに優越している発注事業者が、**自己との取引の過程で発生したこと又は役務の成果物に対して報酬を支払ったことを理由に**、当該役務の成果物に係る権利の取扱いを一方的に決定する場合に…**優越的地位の濫用として問題となる(2 条 9 項 5 号ロ・ハ)**

想定例:
- 権利の譲渡を拒んでいるにもかかわらず、**今後の取引を行わないことを示唆して譲渡を余儀なくさせる**こと
- **作成の目的たる使用の範囲を超えて**一方的に権利を譲渡させること
- 二次利用の例として「**フリーランスが発注事業者の自己使用のために制作したコンピュータープログラムを、他の事業者のために使用する場合**」を明示

### スタートアップ指針(NDA なしの情報開示・知財の無償譲渡)

正式名称: **スタートアップとの事業連携及びスタートアップへの出資に関する指針**(令和 4 年 3 月 31 日、令和 8 年 2 月 19 日改正。公正取引委員会・経済産業省)
URL: https://www.jftc.go.jp/dk/guideline/unyoukijun/startup.html

- **NDA を締結しないまま営業秘密の無償開示等を要請する**行為は、正当な理由がなく、相手が受け入れざるを得ない場合、**優越的地位の濫用として問題となるおそれがある**
  - 掲載事例: 「そのうち契約するから」と言われ NDA なしで**ソースコードを開示させられた**後、相手が類似サービスを発表
- **共同研究の成果に基づく知的財産権の無償提供等を要請する**行為も同様に問題となるおそれ
  - 掲載事例: ひな形を押し付けられ、**PoC・共同研究の成果物の権利が一方的に相手に帰属**する契約になっていた

> **交渉でこれらを直接持ち出すのは最後の手段。** まずは実務的な理由(「他の案件が受けられなくなる」「実績が書けないと営業できない」)で押す。**法令論は、相手の法務が出てきたときの備え**として持っておく。

## 6. 労働者派遣法・偽装請負

正式名称: **労働者派遣事業の適正な運営の確保及び派遣労働者の保護等に関する法律**(昭和 60 年法律第 88 号)
一次情報: https://laws.e-gov.go.jp/law/360AC0000000088

### 37 号告示

正式名称: **労働者派遣事業と請負により行われる事業との区分に関する基準**(昭和 61 年労働省告示第 37 号、最終改正 平成 24 年厚生労働省告示第 518 号)
本文 PDF: https://www.mhlw.go.jp/content/000780136.pdf
疑義応答集: https://www.mhlw.go.jp/bunya/koyou/gigi_outou01.html

**2 条の構造**: 請負の形式で自己の雇用する労働者を従事させる事業主は、**次の 2 号のいずれにも該当する場合を除き、労働者派遣事業を行う事業主とする**。

**1 号: 自己の雇用する労働者の労働力を自ら直接利用するものであること**(イ・ロ・ハすべて)
- **イ** 業務の遂行方法に関する指示・評価等の管理を**自ら**行う
- **ロ** 始業終業時刻・休憩・休日・休暇、時間外労働の指示等の管理を**自ら**行う(単なる把握を除く)
- **ハ** 服務規律に関する指示、労働者の配置の決定・変更を**自ら**行う

**2 号: 請け負った業務を自己の業務として、契約の相手方から独立して処理するものであること**(イ・ロ・ハすべて)
- **イ** 業務処理に要する資金をすべて自らの責任で調達・支弁
- **ロ** 事業主としてのすべての法的責任を負う
- **ハ** 次のいずれかに該当し、**単に肉体的な労働力を提供するものでない**こと — (1) 自己の責任と負担で準備した機械・設備・材料により処理、(2) **自ら行う企画又は自己の有する専門的な技術・経験に基づいて処理**

**3 条**: 2 条各号に該当するように整えていても、**法の規定に違反することを免れるため故意に偽装されたもの**であれば免れない。

> **「業務委託契約書があるから大丈夫」は通らない。** 契約の形式ではなく**実態**で判断される。特に **1 号イ・ロ**(発注者が直接、作業方法や勤務時間を指示している)に該当すると偽装請負と評価され得る。
>
> **常駐案件のレビューでは必ず確認する。** 契約書に「甲は乙の従業員に直接指揮命令を行わない」と書くことは有効だが、**書くだけでなく運用も一致させる必要がある**。運用の実態は契約レビューでは分からないので、**ヒアリングする**。

## 7. 会社法(平成 17 年法律第 86 号) — 利益相反取引

一次情報: https://laws.e-gov.go.jp/law/417AC0000000086 (法令 ID: `417AC0000000086`) / **確認日: 2026-07-28**

**グループ会社間・兼任役員がいる取引で必ず当たる。** 契約書のレビューでは出てこないが、**契約を締結する権限そのものに関わる**ので、締結前に確認する。

| 条 | 見出し | 要点 |
|---|---|---|
| **356 条 1 項** | 競業及び利益相反取引の制限 | 取締役は次の場合、**株主総会**で当該取引につき重要な事実を開示し、その承認を受けなければならない。**1 号 競業取引**(自己又は第三者のために株式会社の事業の部類に属する取引) / **2 号 直接取引**(自己又は第三者のために株式会社と取引) / **3 号 間接取引**(会社が取締役の債務を保証すること等、取締役以外の者との間で会社と取締役の利益が相反する取引) |
| **356 条 2 項** | — | 承認を受けた 2 号・3 号の取引には、**民法 108 条(自己契約・双方代理)を適用しない** |
| **365 条 1 項** | 競業及び取締役会設置会社との取引等の制限 | **取締役会設置会社では、356 条 1 項の「株主総会」を「取締役会」と読み替える** |
| **365 条 2 項** | 同 | 取締役会設置会社では、356 条 1 項各号の取引をした取締役は、**取引後遅滞なく、重要な事実を取締役会に報告**しなければならない |
| **423 条 3 項** | 役員等の株式会社に対する損害賠償責任 | **2 号・3 号の取引で会社に損害が生じたときは、①当該取締役 ②取引を決定した取締役 ③承認決議に賛成した取締役 は任務を怠ったものと推定される**(立証責任が転換) |
| **428 条 1 項** | 取締役が自己のためにした取引に関する特則 | **「自己のためにした」直接取引(2 号)に限り**、423 条 1 項の責任は帰責事由がないことをもって免れられない(無過失責任)。**2 項により責任免除の規定も適用されない** |

**実務上の含意:**

- **同一人物が A 社と B 社の代表取締役を兼任し、A 社 → B 社へ発注する場合、356 条 1 項 2 号の直接取引にあたる。** 「**第三者のために**株式会社と取引」の類型。**両社それぞれで承認手続きが要る**(A 社では B 社のため、B 社では A 社のため)
- **「自己のため」と「第三者のため」を混同しない。** 兼任役員が他社の代表として行う取引は「第三者のため」なので、**428 条の無過失責任は及ばない**。ただし **423 条 3 項の任務懈怠の推定は及ぶ**
- 承認は**取引ごと**が原則。継続的取引は、**種類・数量・金額・期間・価格の算定根拠**という重要な事実を開示したうえで包括承認する実務がある(基本契約の締結時に承認を取る)
- **承認を欠くと 356 条 2 項が働かず、民法 108 条により無権代理と構成されうる。** 加えて 423 条 3 項の推定が効くため、後で会社に損害が出たときに取締役個人が責任を負いやすい
- **議事録が防御になる。** 承認の事実と、開示した重要事実(相手方・内容・金額・期間・価格の算定根拠)を残す

| **132 条 1 項** | 同族会社等の行為又は計算の否認 | **同族会社**等の行為・計算で、容認すると法人税の負担を**不当に減少**させる結果となると認められるものは、税務署長が否認して課税標準・欠損金額・税額を計算できる |

**実務上の含意:**

- **国内の関係会社間取引に移転価格税制は適用されない。** 移転価格税制の対象は**国外**関連者との取引(租税特別措置法)。国内グループ間で問題になるのは **37 条(寄附金)** と **132 条(同族会社の行為計算否認)** の 2 本
- **37 条 8 項は「安く売った側」を捉える規定。** グループ会社に**時価より安く**役務提供すれば、提供した側で寄附金認定されうる。逆に**高すぎる価格で発注**すれば、発注側から受注側への利益移転として問題になる。要は**どちらにも振れる。第三者間価格から乖離させないこと**が肝
- **価格の根拠を残す。** 同種業務の他社向け見積・実績単価、原価計算、稼働時間の記録。「グループだから」で決めた形跡を残さない
- **同一人物が両社を支配する場合、同族会社に該当する可能性が高く 132 条の射程に入る**
- **役員給与の損金不算入(法人税法 34 条)も論点になる**が、条文未確認のため条番号の詳細は書かない。**両社から役員報酬を取る場合の設計は税理士に確認する**

> **税務は弁護士ではなく税理士の領域。** このスキルは論点を特定するところまで。**価格設定と申告の実務は必ず顧問税理士に通す。**

## 追記のルール

このファイルに条番号を足すときは、**必ず一次情報を WebFetch で確認してから**。以下を守る。

1. **条番号・見出し・要点・一次情報の URL** をセットで書く。URL の無い条番号は書かない
2. **記憶で書かない。** 法改正で条番号は動く(→ 冒頭の取適法の例)
3. 確認できなければ**条番号を書かず、制度名だけで書く**(「民法の契約不適合責任」など)
4. **確認日を更新する。** 冒頭の「最終確認日」を書き換える
5. **ガイドライン・告示は改正日を必ず記録する。** 古い PDF が検索上位に残っていることがある(→ 優越的地位濫用ガイドラインの例)

### ⚠️ e-Gov の条文は WebFetch では読めない

このファイルが載せている `laws.e-gov.go.jp/law/...` は **SPA なので WebFetch では本文が 1 文字も取れない**(JS のシェルだけが返る)。上のルール 1「必ず一次情報を WebFetch で確認してから」を、この URL で実行することはできない。**条文を読むときは API を使う。**

```bash
# 法令 ID は各セクションの e-Gov リンクの末尾（例: 民法 = 129AC0000000089）
curl -sS "https://laws.e-gov.go.jp/api/1/lawdata/129AC0000000089"          # v1: XML
curl -sS "https://laws.e-gov.go.jp/api/2/law_data/129AC0000000089?response_format=json"  # v2: JSON
```

- **改正後の現行版が返る**(取適法 `331AC0000000120` で確認済み)。旧版を見たいときは v2 に `&asof=2025-12-31` を付ける
- **sandbox 内では CA 証明書エラー(`curl: (77)`)で落ちる。** その場合は Bash ツールを `dangerouslyDisableSandbox: true` で実行する(条文を読むだけの読み取り専用アクセス)
- 主な法令 ID: 民法 `129AC0000000089` / 著作権法 `345AC0000000048` / 取適法 `331AC0000000120` / フリーランス法 `505AC0000000025` / 独禁法 `322AC0000000054` / 派遣法 `360AC0000000088` / **会社法 `417AC0000000086`** / **法人税法 `340AC0000000034`**

**条番号を指定して 1 条だけ取るのが速い**(法令全体を取ると会社法・法人税法は巨大)。

```bash
curl -sS "https://laws.e-gov.go.jp/api/1/articles;lawId=417AC0000000086;article=356"
```

**公取委・厚労省の PDF も一部は WebFetch が 403 で弾かれる。** その場合はブラウザ相当の User-Agent を付けた curl でダウンロードし、Read で読む。**取得できないことを「存在しない」と書かない。**

# AI 臭の除去チェックリスト

**AI 臭は「文章が下手」ではなく「書きすぎ」。直し方の 9 割は削ることで、書き足すことではない。**

書き上げた後、このファイルを上から当てる。「なんとなく硬い」で止めず、**どの語を消すか**まで決める。各項目は検索できる粒度にしてある。

## 判定の物差し

- **消して意味が変わらない文は消す。** 迷ったら消す。削りすぎは読めば気づくが、残しすぎは誰も気づかない
- **その文が無いと読み手は何を知り損ねるか。** 答えられない文は、書く必要がなかった文
- **一文一義。** 読点で 3 つ以上つないだ文は切る
- **初稿から 2〜3 割減るのが正常。** 1 割も減らないなら点検が甘い

---

## 0. まず一括で置換する

考えなくていい部分。ここを機械的に潰してから中身の点検に入る。

| 出てきたら | 直す |
|---|---|
| 〜することができます / 〜することが可能です | 〜できます |
| 検討を行う / 実施を行う / 対応を行う | 検討する / 実施する / 対応する |
| 〜における | 〜の |
| 〜に関しまして / 〜につきましては | 〜は |
| 〜となっております | 〜です |
| 〜させていただきます | 〜します |
| 〜のような形で / 〜という形で | 削る |
| 〜という点 | 削るか、具体的な名詞に置き換える |
| 非常に / 極めて / 大変 / 十分に | 削る |
| しっかりと / きちんと / 適切に | 削る |
| まず前提として / 前提として | 削る |
| 本資料では / 本稿では | 削る |
| 昨今 / 近年 | 年を書く（「2024 年以降」） |
| 〜と言えるでしょう | 断定するか、削る |
| 〜ではないでしょうか | 〜です |
| 〜と思われます | 誰の判断か書く（「〜と考えます」） |

> 一律に置換しない。社外向けの丁寧文では「〜させていただきます」が要る場面がある。**社内文書では原則消す。**

## 1. 意味のない前置き

本題に入る前に、本題を言い換えた文が 1 つ挟まっている状態。

```
✗ 本施策において重要な点として、まずコストの削減が挙げられます。
✓ この施策の狙いはコスト削減です。

✗ 〜という観点から考えると、導入は妥当と判断できます。
✓ 導入は妥当です。月額が現行より 3 万円下がります。

✗ まず前提として、現状の運用について整理します。
✓ 現状の運用はこうなっています。
```

**判定**: 文の前半を隠して読み、意味が通るならその前半は要らない。「〜について言えば」「〜という点においては」「結論から申し上げますと」は、ほぼ隠して通る。

> 「結論から言うと」は書かない。**結論を冒頭に置けば、そう宣言する必要がない。**

## 2. 中身のない強調

強調語が、根拠ではなく熱量で押している状態。

```
✗ セキュリティ対策は非常に重要です。
✓ 管理画面に IP 制限がありません。社外の回線からログインできます。

✗ この施策は大きな価値があります。
✓ 問い合わせ対応が月 20 時間減ります。

✗ 定期的な見直しは必須です。
✓ 四半期ごとに私が棚卸しし、結果を共有します。
```

**判定**: 「重要」「必須」「大きな」を消し、代わりに**それが重要だと読み手が自分で判断できる事実**を置く。置ける事実が無いなら、その主張自体を落とす。

## 3. 数字のない形容

```
✗ 大幅にコストを削減できます。
✓ 月額 12 万円が 7 万円になります。

✗ 多くのユーザーが不便を感じています。
✓ 直近 1 か月の問い合わせ 43 件のうち、18 件が同じ操作についてでした。

✗ かなり時間がかかっています。
✓ 1 件 40 分、月 30 件で 20 時間です。

✗ 早急な対応が必要です。
✓ 今月末までに直さないと、来期の請求に間に合いません。
```

**判定**: 「大幅・かなり・多く・急激・早急・大量・一部の」を検索する。数字を出せないなら、程度を語らず事実だけ書く。**根拠のない「大幅に」より、何も付けない「削減できます」のほうが強い。**

## 4. 何でも箇条書きにする癖

項目のあいだに関係があるのに、並列に潰して書いている状態。箇条書きにしていいのは次の 3 つ。

| 使っていい | 例 |
|---|---|
| **並列**（順序も因果も無い） | 対象システム、参加者、必要書類 |
| **手順**（順序がある） | 申請 → 承認 → 反映 |
| **選択肢**（読み手が選ぶ） | 案 A / 案 B / 案 C |

因果・条件・時系列・比較は、地の文か表で書く。

```
✗
- 現在の契約は 3 月末で終了
- 更新には稟議が必要
- 稟議の承認には 2 週間かかる

✓ 現在の契約は 3 月末で終了します。更新には稟議が必要で、承認まで 2 週間かかるため、
  遅くとも 3 月上旬には起票が要ります。
```

悪い例は事実を 3 つ並べただけで、**肝心の「だから今動く必要がある」が消えている**。因果を箇条書きにすると、つなぐ仕事が読み手に押しつけられる。

> 箇条書きが 2 階層以上ネストしたら、構成が間違っている。表にするか、見出しで割る。

## 5. 無理な 3 点セット

理由が 2 つしか無いのに、3 つ目を捻り出している状態。

```
✗ 導入する理由は 3 点あります。
   1. 運用工数が減る
   2. 障害時の復旧が早くなる
   3. 将来的な拡張性も期待できる

✓ 導入する理由は 2 点です。運用工数が月 20 時間減ること、
  障害時の復旧が半日から 1 時間に短縮されることです。
```

捻り出した 3 点目は「将来的な拡張性」「柔軟な対応が可能になる」「属人化の解消」あたりに落ち着く。どれも中身が無い。**2 つなら 2 つと書く。** 数が揃っていないことを気にするのは書き手だけで、読み手は気にしない。

**判定**: 各項目に数字か具体的な事実が付いているか。1 つだけ抽象的な項目があれば、それが捻り出した項目。

## 6. 結論のない締め

```
✗ 今後の検討が重要です。
✗ 引き続き注視が必要です。
✗ 状況に応じて柔軟に対応していきます。
✗ 関係者と連携しながら進めてまいります。
```

いずれも「何も決まっていない」の言い換え。締めには次のどれかを書く。

| 締めに書くもの | 例 |
|---|---|
| 決まったこと | A 案で進めます |
| 依頼 | 15 日までに承認をお願いします |
| 次の行動・担当・期限 | 私が来週水曜までに見積もりを取り、共有します |
| 決まっていないことの明示 | 予算が未確定のため、B 案の判断は 4 月の予算確定後に行います |

```
✗ 引き続き状況を注視し、必要に応じて対応を検討します。
✓ 週次でエラー率を確認します。5% を超えたら、私からロールバックを提案します。
```

**判定**: 最後の段落に主語・動詞・期限が揃っているか。揃っていなければ、その段落は何も言っていない。

## 7. 主語の欠落

```
✗ 早めの対応が必要と思われます。
✓ 経理に、月末までに締め日の変更を依頼してください。

✗ 運用ルールの整備が求められます。
✓ 運用ルールは私が来月中に草案を作ります。レビューをお願いします。

✗ 認識の共有が不十分でした。
✓ 仕様変更を開発チームに伝えていませんでした。私の伝達漏れです。
```

**判定**: 「〜が必要」「〜が求められる」「〜すべき」「〜されている」を検索し、**誰が・いつまでに**を補う。受け身と名詞止めは責任の所在を隠す形になりやすい。詫びる文で主語を省くと、詫びていないのと同じに読まれる。

## 8. 接続詞でつなぎすぎる

「しかし」「一方で」「また」「そのため」が段落の頭に並んでいる状態。とくに逆接の乱用は、自分の主張を自分で打ち消す。

```
✗ A 案が有力です。しかし、コストは高くなります。一方で、B 案は安価です。
  ただし、実績がありません。したがって、慎重な検討が必要です。

✓ A 案を推します。B 案より月 3 万円高いですが、同規模の導入実績が 5 社あります。
  B 案には実績がありません。
```

逆接を重ねるほど結論が薄まる。**トレードオフは「〜だが〜」で 1 文にまとめ、どちらを取るかを言い切る。**

**判定**: 段落頭の接続詞を全部消して読む。それで通るなら元から要らなかった。消すと通らない箇所は因果が飛んでいる箇所で、そこに足すべきは接続詞ではなく説明。

## 9. 対句・体言止め・見出しの刻みすぎ

```
✗ 迅速な対応と、確実な実行を。
✓ 今週中に対応します。

✗ 課題は 3 つ。原因は 1 つ。
✓ 課題は 3 つありますが、原因はどれも同じで、承認フローが二重になっていることです。
```

体言止めはリズムを作るが、**動詞を消すぶん「誰が何をするか」も一緒に消える**。スライドの見出しでは使えても、文書の本文では使わない。

見出しについては、本文が 2〜3 行しか無い見出しが並んでいたら刻みすぎ。見出しを削って地の文でつなぐ。目安として A4 1 枚に見出しが 6 つ以上あれば多い。

## 10. 抽象名詞の重ね技

「〜性」「〜化」「〜的」で終わる語が 1 文に 2 つ以上あると、意味が消える。

```
✗ 属人性の排除と業務の標準化により、運用の安定的な継続が可能となります。
✓ 手順書を作れば、担当者が休んでも他の人が回せます。

✗ 全社的な観点からの最適化が課題です。
✓ 部署ごとに別のツールを使っていて、集計が手作業になっています。
```

**判定**: 「性・化・的・観点・推進・強化・最適化・可視化」を検索する。消して具体的な動作に書き換えられないなら、書き手自身が中身を分かっていない。その場合は文を直すのではなく、分かるまで調べるか `【要確認】` を残す。
